# 黄金看板静态展示版

本地版保持原样。静态版复用 Vue/ECharts 页面，只读取 `data/snapshot.json`，上线后不需要 Python、电脑开机或临时隧道，也不会随本机文件自动更新。

## 生成、预览与更新

在项目根目录的 PowerShell 执行（复用已有依赖）：

```powershell
.\后端\venv\Scripts\python.exe -B .\展示版\export_snapshot.py
cd .\前端
npm run build:pages
npm run preview:pages
```

打开 http://127.0.0.1:4173/pages-preview/ 。关闭预览终端或按 Ctrl+C 仅停止本地预览。

数据文件更新后重跑导出与构建；核对页面后，提交新的 `展示版/数据/data/snapshot.json` 并重新发布。页面“重新加载展示数据”只读取服务器现有快照。快照生成时间、指标观察日期分别标注；滞后状态以快照生成时为准。

## 公开内容

`公开范围.json` 是导出白名单，包含现有卡片和图表实际使用的指标、七只 ETF 的规模/份额，以及排除特殊口径列后的央行原始排序序列。纯卡片指标只保留最新两期，其余保留筛选所需历史与真实空值。未展示的 ETF 净值、SPDR 价格/成交量等不导出。健康度只包含展示指标。

正式数据仅一个 JSON，另有网站图标；不发布原始 Excel/CSV、完整接口元数据、本机路径、Python 环境。**JSON 中数值及历史可被下载，文件格式不会消除公开风险。发布前须确认数据及品牌展示权限。** 对不适合公开的来源，把文件名加入 `withheld_sources`；单指标在 `withheld_indicators` 中填写“指标ID: 原因”，重新导出后保留缺失提示。

## GitHub Pages 发布

仓库为 https://github.com/meiqiguanzhiking-byte/gold-dashboard 。用户已于 2026-10-23 确认本次数据、历史序列与页面品牌完全公开。Git 登录使用 GitHub 自带认证，不在聊天中提供密码或令牌。导出脚本及 Python 后端仅保留本机，不提交此展示仓库。

仓库 Settings → Pages → Source 选择 GitHub Actions；从 Actions 手动运行“发布黄金看板静态展示版”，确认公开选项。流程只构建前端和上传 `展示版/dist`，使用 Pages 返回的实际子路径，不猜仓库名。不执行云端 Python 导出。普通推送不会自动发布。

本地默认使用可移动的 `./` 资源路径；`pages-preview` 只是子路径验证用名称。正式路径由工作流从 Pages 配置取得，本仓库子路径为 `/gold-dashboard/`。正式访问地址以 Pages 部署结果为准。根目录 `.gitignore` 排除原始文件、依赖、密钥和构建产物，精确放行要发布的单个 JSON。不要使用 `git add -f` 绕过排除规则。

## 检查与限制

预览运行时在前端目录执行 `npm run check:pages`，检查使用真实快照、不写截图或报告。价格锚点、全球央行合计仍缺失；央行机构/单位及 COMEX 已质押扣减定义的现有限制原样保留，不补造数据。
