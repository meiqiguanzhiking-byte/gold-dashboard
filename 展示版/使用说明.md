# 黄金看板静态展示版

静态版复用 Vue/ECharts 页面，从已审阅的 `data/snapshot.json` 构建首屏与历史分片，上线后不需要 Python、电脑开机或临时隧道，也不会随本机文件自动更新。每日速递和健康度元信息直接随 HTML 载入，不再等待完整快照下载；国内、国外的完整历史在切页时按分类加载，保留全部原始观察日期、数值与空值。

公网网址：https://meiqiguanzhiking-byte.github.io/gold-dashboard/ 。网站可供其他人直接查看，无需保持本机程序运行。

## 生成、预览与更新

在项目根目录的 PowerShell 执行（复用已有依赖）：

```powershell
.\后端\venv\Scripts\python.exe -B .\展示版\export_snapshot.py
cd .\前端
npm run build:pages -- --base=/pages-preview/
npm run preview:pages
```

打开 http://127.0.0.1:4173/pages-preview/ 。关闭预览终端或按 Ctrl+C 仅停止本地预览。

数据文件更新后，先按文末白名单同步获准公开的13个原始文件副本，再重跑导出与构建；核对页面后，在项目根目录执行 `git add -- 全量数据 前端/src 前端/checks 展示版/export_snapshot.py 展示版/数据/data/snapshot.json 展示版/使用说明.md`、`git diff --cached --stat`、`git commit -m "Update dashboard interface and data"` 和 `git push`，再按下文手动运行发布流程。这样同时提交最新界面、数据与展示快照；构建产物由 GitHub Actions 生成。页面“重新加载展示数据”只读取服务器现有快照。快照生成时间、指标观察日期分别标注；滞后状态以快照生成时为准。

## 公开内容

国外页“远期 COMEX期货与汇率期货”读取`COMEX黄金与汇率期货_北京时间15收盘价.csv`。COMEX黄金及SGX美元兑离岸人民币各显示一条最近未过期偶数月合约原始收盘价连续线，北京时间15:00；按原表当日列示合约选约，不复权，保留换约价差，不回切旧约。空值直连、不补值；先构建全部历史再筛选日期。悬停显示到期月、原表标识、原始收盘价及换约信息。原表au标识仅用于关联，不视为境外官方代码。来源分别为Barchart官网→CME芝商所、Barchart官网→SGX新加坡交易所，健康度及静态版同步接入，原始CSV不公开复制。

`公开范围.json` 是导出白名单，包含现有卡片和图表实际使用的指标、七只 ETF 的规模/份额，以及排除特殊口径列后的央行原始排序序列。纯卡片指标只保留最新两期，其余保留筛选所需历史与真实空值。境内ETF合计份额用于趋势折线，须与七只分基金份额保留相同的完整历史，不纳入仅最新两期的裁剪。未展示的 ETF 净值、SPDR 价格/成交量等不导出。健康度只包含展示指标。

正式快照仍为一个 JSON；构建时另行生成 `data/bootstrap.json` 和带内容哈希的历史分片，均只来自同一份已审阅快照。历史分片每个不超过96KiB，最多并发3个下载，临时网络故障最多尝试3次、每次60秒超时；成功分片按版本复用浏览器缓存及当前页面内存。失败分类可独立重试，不会清空每日速递或其他分类。点击“重新加载展示数据”先检查小索引的新版本，再加载当前页历史，刷新失败保留已载入数据。完整 `data/snapshot.json` 保留供兼容和核对，当前页面不再下载它。这些措施减少慢网络负担，不能保证被网络阻断的 GitHub 域名可访问。

网站产物不包含原始 Excel/CSV、完整接口元数据、本机路径或 Python 环境。用户已于2026-10-26确认全部13个原始Excel/CSV可以公开，原文件副本同步在仓库根目录`全量数据/`，可从公开仓库下载；它们不进入Pages产物。**JSON 中数值及历史可被下载，文件格式不会消除公开风险。发布前须确认数据及品牌展示权限。** 对不适合公开的来源，把文件名加入 `withheld_sources`；单指标在 `withheld_indicators` 中填写“指标ID: 原因”，重新导出后保留缺失提示。

## GitHub Pages 发布

仓库为 https://github.com/meiqiguanzhiking-byte/gold-dashboard 。用户已于 2026-10-23 确认原有来源数据、历史序列与页面品牌完全公开；2026-10-26另行确认全量数据及新增价格、汇率来源可以公开。Git 登录使用 GitHub 自带认证，不在聊天中提供密码或令牌。仓库包含前后端源码和快照导出脚本，Python虚拟环境和私人文件不提交，原始数据仅纳入已明确确认的13个文件；GitHub Pages仍只部署静态产物，不运行Python后端。

本地后端使用Python 3.12及以上，在`后端`目录安装`requirements.txt`后，执行`python -B -m uvicorn main:app --host 127.0.0.1 --port 8000 --no-access-log --log-level warning`。默认只读项目旁的`数据构建/数据更新/全量数据`目录，该目录不存在时回退至仓库的`全量数据/`，也可通过`GOLD_DATA_DIR`环境变量指定数据位置。前端在`前端`目录执行`npm run dev`。本地开发默认使用回环地址；额外开发域名可通过`GOLD_ALLOWED_HOSTS`指定具体域名，静态展示不依赖此设置。

仓库 Settings → Pages → Source 选择 GitHub Actions；从 Actions 手动运行“发布黄金看板静态展示版”，确认公开选项。流程只构建前端和上传 `展示版/dist`，使用 Pages 返回的实际子路径，不猜仓库名。不执行云端 Python 导出。普通推送不会自动发布。

本地默认使用可移动的 `./` 资源路径；`pages-preview` 只是子路径验证用名称。正式路径由工作流从 Pages 配置取得，本仓库子路径为 `/gold-dashboard/`。正式访问地址以 Pages 部署结果为准。根目录 `.gitignore` 默认排除原始文件、依赖、密钥和构建产物，精确放行展示JSON及已确认的13个原始数据文件。不要使用 `git add -f` 绕过排除规则。

## 检查与限制

顶部“每日速递 / 国内 / 国外 / 数据健康度”手动切换，默认每日速递；切换保留各页筛选、时间范围、图例与缩放状态。每日指标按“价差、现期、远期、风险波动、宏观、ETF份额、交易与持仓、库存与交割”分为八组、25张卡。国内期货使用最近偶数月合约原始收盘价，悬停合约名称查看当日全部合约；涨跌比较同一合约前一期，不把换月价差作为涨跌。国际黄金和离岸人民币期货展示最近及第二近偶数月。期货价差沿用主力、次主力原始价差序列（不复权）。全球ETF周/月度展示源数据净流量；CFTC四项合并，净多头占比从比例换算为百分数；COMEX四类库存同日展示，已质押为注册库存子集，不重复加总。央行黄金储备及伦敦黄金库存为月频。各卡标明最新观察日期，详情跳转恢复目标版块。

国内黄金期货卡片在当前合约收盘价下方展示“升贴水率”，悬停标题可查看同一观察日全部合约的升贴水率、最后交易日及剩余天数。卡片及悬浮明细均展示较上一交易观察日的百分点变化：两期采用当前同一合约，分别以各自同日期现原价及剩余自然日计算，再相减；前期价格缺失不跨期补值，换月不与旧主力混比。公式为(期货原始收盘价−Au99.99现货收盘价)÷Au99.99现货收盘价×365÷剩余自然日，换算为百分比；期现价格与剩余天数统一使用期货报价观察日，不使用看板报告日、使用同合约原始收盘价计算基差。现货必须严格匹配同日，不前填；到期、剩余天数为0、同日期货/现货或已确认到期日缺失时不计算。

最后交易日只读[上期所合约参数](https://www.shfe.com.cn/products/futures/metal/ferrousandpreciousmetal/au_f/)的EXPIREDATE字段，包含官方休市顺延及调整；不将交割月份的15日直接作为实际到期日。本地重载及快照导出额外读取最新报价日官方ContractBaseInfo报表，最新两期合约明细附具体到期日、出处URL和核对日期。网络不可用时仅复用代码中已逐项核实的2026-11-03合约日期；未知合约标记“最后交易日尚未确认”，不猜测。静态网站直接使用已导出的确认日期，无需访问交易所接口。正式CSV/Excel价格数据保持只读。

“价差期限结构”位于指标变动上方：横轴为黄金现价价差、当前主力合约价差、当前次主力合约价差，合约名称随现有序列自动更新，纵轴单位元/克。最新三个价差以实线连接；T-5、T-10仅连接两项期货价差，分别使用虚线和点虚线。历史口径沿用每日指标卡的主力、次主力原始价差序列（不复权），按各自前5、10条交易观察记录回看，不按自然日、不跳过空值，不改算固定当前合约的原始价差。悬浮显示每点数值、真实观察日期及当期合约。静态首屏额外保留两条期货价差及合约说明最近11期，保持与完整序列相同的期限结构；不足历史或空值不补零。

每日速递可分别勾选“价差期限结构、指标变动、阈值筛选、每日指标”，附全选和清空。七类阈值及变动卡片依次为：价差、价格、波动率、利率、份额、成交量、持仓量，阈值保存在当前浏览器；价差按元/克绝对变化筛选，其余按变化百分比，严格大于阈值，前一期为空或为零不计算百分比，不跨期找基准。新增日频筛选覆盖两项黄金期货价差、国内最近偶数月合约收盘价、国际黄金及美元兑离岸人民币各两期期货价格、GVZ，以及COMEX注册、已质押、合格和总库存。期货价格归价格、期货价差归价差、GVZ归波动率，四类库存按用户指定归持仓量（0—1%，默认0.2%）。合约与比较基准复用每日指标卡，不跨合约比较原始收盘价；本次不新增周月频筛选。延期费支付方向固定展示在最后。Au(T+D)保留成交量、持仓量、延期费方向及近7个交易观测日多空统计，悬停统计标题查看日期和支付方向。国内ETF只显示七只合计份额，SPDR黄金份额保持吨数；不展示七只单只ETF。报告日为北京时间当前日期，缓存或快照时间与各指标观察日期分别标注。国内、国外、健康度的显示版块选择也保存在当前浏览器。

黄金现价区使用上金所Au99.99收盘价（元/克）及上游20/60日年化历史波动率（日对数收益率、样本标准差、252日年化），区间筛选不重算。用户已于2026-10-26确认新增来源及派生波动率可以公开，静态快照现已纳入这些指标。后续新来源仍需单独确认，未经确认保持缺失提示。

国内现价版块下方的“远期 黄金期货与价差”读取`黄金期货.csv`及`COMEX黄金与汇率期货_北京时间15收盘价.csv`。左图为最近偶数月合约国内原始收盘价，国内最后报价日之后换约，不复权。右图分别以最近和第二近偶数月合约计算同日同月原始价差＝国内原价−COMEX原价×USDCNH期货原价÷31.1034768（元/克），不复权，保留换约价差。海外报价日期为右表，只按同日同月匹配，缺项为空，折线跨空值直连，不前填、不移日期、不使用现货汇率替代。悬停显示所选合约及各原始报价。含CNH/CNY口径与收盘时点差异。每日速递、价差期限结构、变动与阈值筛选、交叉图表和静态展示均沿用相同的不复权序列。

国内“上期所黄金期货”中，成交量与持仓量图右侧为逐日升贴水率表，列为期货名称、期货价格、Au99.99收盘价、基差、升贴水率。右上角日期选项覆盖CSV全部历史报价日期，默认最新日期；每个日期显示当天CSV中的全部合约，包括奇数月合约，不因现货或升贴水率缺失而删除合约行，切页保留所选日期。期货和现货价格分别读取`黄金期货.csv`及`黄金现货价格.xlsx`的“黄金现货价格”工作表，同日匹配，不复权、不跨日期填补。价格与基差单位元/克，基差＝期货−现货，年化升贴水率＝基差÷现货×365÷剩余自然日×100%，与每日速递共用计算函数。已到期合约取CSV最后有效报价日；在市合约按交割月15日估算，优先采用上期所确认的顺延日期，周末顺延，未确认的节假日调整标为估算。缺项或剩余天数≤0的相应字段显示“—”；悬停合约名称或升贴水率可查看终点日期、剩余天数、依据及缺失原因。静态版保留完整报价历史，首屏每日速递仍只读取所需最近两期。窄屏表格可横向滚动。

折线图可拖动底部时间滑块或在图内滚轮缩放；纵轴随可见日期及图例启用序列自动调整，“重置缩放”恢复所选时间区间。柱状和堆叠面积轴保留零基线，请结合纵轴刻度判断真实变化幅度。

Au(T+D) 图右侧按最新观察日统计最近7个、30个交易观测日的延期费支付方向：“空支付给多”计空方支付，“多支付给空”计多方支付。交收平衡、方向缺失单列，不补周末/节假日，不等同自然日计费天数或费用金额；窗口不受左图缩放影响。静态快照仅额外保留最近30条交收方向，重新生成、构建并发布后更新。

预览运行时在前端目录执行 `npm run check:pages`，检查使用真实快照、不写截图或报告。COMEX 已质押扣减定义仍待确认，不补造数据。

现有全球央行CSV曾将未报告空白补零，本地刷新和快照导出均只读留存WGC原始`Changes_latest_as_of_Oct2026_IFS.xlsx`的Monthly表逐月核对，恢复空白后计数。默认原件在项目旁`数据构建/10、全球央行购金 2002.01-2026.08/原始数据/`；新版本用环境变量`GOLD_CENTRAL_BANK_CHANGES_FILE`指定原始Changes工作簿后重启后端/重新导出。原件缺失、机构字段变化或某月与正式CSV不匹配时，对应月份显示数据暂缺，不凭CSV补零推断报告数。原件不复制、不上传；静态版只保留页面所需汇总、报告数、纳入实体历史和公开范围说明。

国外页“13 COMEX实物交割”位于全球央行购金下方，左右分别为标准黄金期货GC和微型黄金期货MGC。只读正式目录`黄金交割.xlsx`的GC/MGC表，首两列为`机构名称（C/H）`、`I/S`，其余为真实月份日期。源值已由上游按GC每手100、MGC每手10金衡盎司及31.1034768克/金衡盎司换算为公吨，页面不再换算。每个机构C/H账户仅显示一条左侧标签，I交付绘于零线左侧、S接收绘于右侧，月份颜色对应两侧，不使用接收减交付的净值。默认各合约最近3个有数值月份，可独立选择月份、切换图例并滚动查看全部机构；全空月份不默认入选，空白不补0。交割通知的名义数量不等于实物出入库，MGC涉及部分仓单权益，两合约不相加。观察月份、文件更新时间和快照时间分别保留，发布日期未知为null。动态版随缓存刷新读取；静态版通过同一JSON的`deliveries`字段提供，缺失旧快照显示数据暂缺。`include_comex_deliveries`控制后续导出，`withheld_sources`亦可屏蔽该来源。交割原始工作簿不纳入公开仓库，Pages仅通过快照展示图表所需序列。
