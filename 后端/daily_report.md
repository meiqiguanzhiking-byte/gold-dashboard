# 文字日报：每日生成、成功锁定

后端自动读取同目录 `.env` 中的 `GOLD_REPORT_AI_URL`、`GOLD_REPORT_AI_MODEL` 和 `GOLD_REPORT_AI_KEY`。密钥只用于后端请求头，不进入前端、日志或公开快照。进程环境变量优先于文件配置。

## 调用与费用控制

- 后端运行期间每30秒检查CSV/XLSX变更，连续两轮确认文件稳定（约60秒）后重新加载。源文件可读、主要价格/价差不缺失且观察日期一致，才启动AI流程；周月频指标保留各自最新日期。页面每30秒读取后端批次并同步新数据，不靠用户点击刷新。启动后端和手动刷新也走相同检查。页面接口只读取结果，不启动生成；切换版本、复制、浏览器刷新和滑块操作不会调用模型。
- 固定使用每日默认阈值生成一份AI日报。“AI优化”全天可查看这份已保存稿，不受滑块调整影响；“数值规则”随当前阈值更新。切换两页只切换展示内容，不触发生成。
- 同一主要价格观察日内数据调整，动态页仍保留该期AI，标明它是已保存稿；主要价格观察日推进（如9号更新到10号）后开启新一期生成，不能被当天早前生成的9号稿锁住。数值规则、图表和卡片更新为新批次。公开导出仍要求事实指纹完全匹配。刷新源文件存在读取失败时暂停生成，避免为文件更新中的残缺数据消耗额度。
- 使用日报事实指纹识别数据是否改变，不以加载时间、配置、提示词版本或页面阈值作为新增付费条件。数据未变时跨日也复用原文，保留正文的原报告日期和生成时间。
- 每个北京时间自然日最多5次模型请求，包含首次和失败重试。每次只有一次Chat Completions请求，没有第二次模型语义审校。校验失败、超时或服务错误可在剩余额度内重试；一旦成功立即停止并持久保存。同一期主要价格观察日成功后不再重复生成；观察日推进可生成新一期，但各期仍共享当天累计5次请求上限。
- 每次请求输入加输出合计上限15000 tokens。先用消息UTF-8字节数加封装余量计算保守输入预算，再把剩余额度传给模型的max_tokens；并非简单地允许输出15000。输入过长无法留下输出预算时不发送请求。提示词和结构化字段已精简，减少重复输入。环境变量 `GOLD_REPORT_AI_MAX_TOKENS` 可进一步调低输出额度，不能绕过合计限制；诊断也不能绕过。DeepSeek关闭额外推理。
- 每次有模型响应时，将接口返回的输入、输出、总token数及结束原因写入持久化日报的model_usage，失败响应也保留。不保存API密钥或请求头。
- 超时默认20秒，本机配置为60秒，单次最多120秒。等待期间看板和规则日报正常可用。

额度与成功/失败结果保存到项目 `.tools/daily-report.sqlite3`，该目录已被Git忽略。SQLite在请求前原子记录尝试次数，多个请求或进程不能重复占用同一额度；重启、网络超时、前端取消均不清零。进程中断后的占用至少锁定180秒，之后只有数据准备流程可以用剩余额度继续。不要删除此文件，否则会丢失费用记录和已有日报。

## 事实保护

规则文案复用 `前端/report-bridge.mjs` 和前端原有数据口径。AI可重组句子，但数字、日期、单位、指标名称与方向均使用占位符保护。Python本地核对保护符归属、完整性、数值和日期槽位、单位与指标名称，拒绝新数字、买卖建议等。校验失败文案不显示、不导出；后续有限重试仍须通过完整校验。

语义解释边界写入生成提示词，校验过程不会额外调用大模型。确定性的数值校验不等于完整语义审校，解释仍需研究人员阅读确认。

## 静态快照

`展示版/export_snapshot.py` 只读取缓存，绝不调用模型。先按公开范围清除受限来源及其派生指标，再核对这份公开日报的事实指纹；只有与已保存日报完全一致时才复用AI，否则只导出规则版，不能拿含非公开事实的文案填充。

GitHub页面只读快照，不请求Python、`/api` 或模型。静态页面同样支持版本切换和复制，显示报告日期、主要观察日期、生成时间。导出与构建不会另花模型费用：

```powershell
.\后端\venv\Scripts\python.exe .\展示版\export_snapshot.py
Set-Location .\前端
npm run build:pages
```

## 无付费验证

专项测试只使用本机模拟模型与临时SQLite，不访问真实DeepSeek或真实费用记录：

